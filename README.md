# hello-claude-pr

A tiny practice repository for learning the GitHub pull request workflow.

## What this is

`greet.py` contains a single `greet` function that returns a friendly
greeting. `test_greet.py` contains a few tests for it.

## Usage

```bash
python greet.py Alice
```

## Running tests

```bash
python -m unittest discover
```

## Contributing

This repo is just for practicing PRs, but the usual flow applies:
create a branch, make a small change, and open a pull request so it
can be reviewed before merging.
